A lightweight multilingual layer built specifically for Tajemství JAMU.

== Description ==

The plugin stores translated content in its own table while preserving the
original WordPress post, term, product and variation IDs. It provides localized
routes, frontend content filters, canonical and hreflang tags, a localized XML
sitemap, WooCommerce schema localization and translation editing fields.

Languages: Czech (source), English, German and Polish.

== Shortcode ==

`[jamu_language_switcher]`

== Data ownership ==

Uninstalling or deactivating the plugin does not delete translations. This is
intentional. Product prices, stock, SKUs, variations, taxes, shipping, coupons
and orders are never copied into the translation table.
